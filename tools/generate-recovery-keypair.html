CipherSeal Vault — Owner Recovery Key Generator

Run this file locally and offline (double-click it, no server needed) to create your own RSA-OAEP 2048 key pair for the "Allow owner recovery" feature. It never sends anything anywhere — open the browser's Network tab if you want to confirm that yourself.

Keep recovery-private-key.json somewhere safe and offline (a USB drive, not this repository). Only recovery-public-key.json goes into data/ on the live site.
